| :---: | :--------------------------------------------- | :------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |

|   №   | Требование                                                                  |
| :---: | :-------------------------------------------------------------------------- |
|  P1   | Ставки в CRM банка должны обновляться в реальном времени (при запросе)      |
|  P2   | Выгрузка файла для партнера должна происходить не реже 1 раза в день        |

|  S1   | Использование существующего SFTP-сервера банка для передачи файлов партнеру |
|  S2   | Формат файла: CSV (согласован с партнером)                                  |
|  +R1  | Обеспечение безопасности передачи файлов (шифрование)                       |

### **Решение**

#### Диаграммы:

- **Диаграмма контейнеров**: [Контейнер-диаграмма](/out/Task4/container_diagram.png)


#### Компоненты решения:

1. **Депозитный сервис (расширение)**:
   - **REST API для CRM банка**: Конечная точка `/rates` (GET) возвращает JSON с актуальными ставками
   - **Модуль выгрузки ставок**:
        - Формирует CSV-файл по расписанию
        - Загружает файл на SFTP-сервер партнера с использованием учетных данных
2. **CRM банка**:
   - Интеграция с API Депозитного сервиса для получения ставок (при открытии раздела или по таймеру)
3. **SFTP-сервер банка**:
   - Временное хранение файлов перед передачей партнеру
   - Настраивается доступ для партнера (только чтение)
4. **Партнерский кол-центр**:
   - Автоматическая или ручная загрузка файла с SFTP-сервера банка
#### Обоснование:
- **Реальное время для CRM банка**: API позволяет получать самые свежие данные.
- **SFTP для партнера**: Удовлетворяет ограничению партнера (нет API) и обеспечивает безопасность
- **CSV формат**: Простота реализации и согласования

### **Альтернативы**  
| Альтернатива                      | Комментарий                                                                                            |
| --------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Прямой доступ CRM банка к АБС     | **Недостатки:** Нарушает изоляцию АБС, сложность реализации. **Отказ:** Не соответствует архитектуре.  |
| Единый SFTP для обоих кол-центров | **Недостатки:** CRM банка может работать в реальном времени. **Отказ:** Для банка нужен онлайн-доступ. |
| Email для передачи файла партнеру | **Недостатки:** Ненадежно, нет гарантии доставки. **Отказ:** SFTP более надежен.                       |
---

### **Недостатки, ограничения, риски**  
1. **Недостатки**:
   - Партнер получает ставки с задержкой (до 24 часов)
2. **Ограничения**:
   - Формат CSV может быть недостаточен для сложных структур (но в данном случае ставки простые)
3. **Риски**:
   - **Недоступность SFTP**: Файл не будет доставлен
   - **Смена формата партнером**: Требуется согласование
4. **Компромиссы**:
   - Для партнера выбрана периодическая выгрузка, а не реальное время

### **Список задач для систем**
1. **Депозитный сервис**:
   - Реализовать REST API для получения ставок (GET /rates)
   - Реализовать scheduled job для генерации CSV-файла
   - Реализовать загрузку файла на SFTP (с обработкой ошибок)
   - Написать документацию API
2. **CRM банка**:
   - Интеграция с API Депозитного сервиса (получение ставок)
   - Обновление интерфейса для отображения ставок
3. **Инфраструктура**:
   - Настройка SFTP-сервера для партнера
   - Выделение учетных данных для партнера
4. **Партнерский кол-центр**:
   - Настройка автоматической загрузки файла с SFTP
   - Обновление своей системы для импорта CSV
